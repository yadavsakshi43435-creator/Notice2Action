\# Notice2Action



\### From College Notices to Clear Student Actions



Notice2Action is an AI-powered College Notice Intelligence and Student Action Management System.



\## Problem

Students receive lengthy college notices containing important deadlines, fees, events and instructions. Finding and managing these actions can be difficult.



\## Our Solution

Notice2Action helps students upload college notice PDFs, extract important information, understand instructions and convert them into manageable tasks.



\## Key Features

\- PDF Notice Upload

\- Automatic Text Extraction

\- Deadline and Amount Detection

\- Action Identification

\- Simple Explanations

\- Student Verification and Editing

\- Task Management Dashboard



\## Technology Stack

\- Python

\- Streamlit

\- PyMuPDF

\- Pandas

\- SQLite

\- Gemini API (Optional)
